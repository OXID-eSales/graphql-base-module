# Changelog
All notable changes to this project will be documented in this file.

## [12.0.2] - 2026-04-14

### Fixed
- Composer throws security issues for concrete graphl-version

## [12.0.1] - 2026-03-18

### Fixed
- Graphqlite is incompatible with webonyx/graphql-php v15.31

## [12.0.0] - 2025-10-28

### Changed
- Update module to work with OXID eShop 7.4

### Added
- A `matches` method was added to `FilterInterface` (and it's implementations) to allow checking if a filter matches a given value.
